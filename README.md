# Проект: интеллектуальный тренажёр «Своя игра»
Приложение представляет собой интеллектуальный тренажёр с базой вопросов, распределённых по тематическим категориям и уровням сложности. Каждому вопросу присваивается определённая стоимость в баллах: 100, 200, 300, 400 или 500.

## Основные возможности приложения:
- Режим тренировки. Пользователь выбирает интересующие его категории и сложность вопросов либо запускает смешанную тренировку.
- Режим классической игры. Вопросы представлены в виде игрового поля с тематическими категориями и стоимостью заданий. Пользователь самостоятельно выбирает вопросы, отвечает на них и набирает баллы.
- Автоматическая проверка ответов. Вопросы предполагают преимущественно короткие и однозначные ответы. Для проверки используется сравнение с эталонным ответом с возможностью учёта альтернативных формулировок.
- Сбор статистики. Приложение сохраняет историю игр, количество правильных и неправильных ответов, набранные баллы, процент успешности по каждой категории и уровню сложности.
- Система достижений. Пользователь получает достижения за определённое количество правильных ответов, успешное прохождение категорий и улучшение личных результатов.

## Распределение обязанностей:

### Участник 1. Игровая логика и база вопросов
**Цель:** разработка игровой механики и организация работы с вопросами.

Задачи:
- Разработка структуры классов Question, Category, Game, GameSession.
- Создание базы вопросов с категориями, уровнями сложности и стоимостью в баллах.
- Реализация загрузки, хранения и фильтрации вопросов.
- Разработка механизма формирования игрового поля.
- Реализация логики выбора вопросов, начисления баллов и завершения игры.
- Разработка механизма проверки ответов с учётом альтернативных формулировок.
- Тестирование игровой логики.

### Участник 2. Графический интерфейс и взаимодействие с пользователем
**Цель:** разработка интерфейса приложения и интеграция с игровой логикой.

Задачи:
- Разработка дизайна и структуры пользовательского интерфейса.
- Создание главного меню и навигации между разделами.
- Разработка игрового поля с категориями и стоимостью вопросов.
- Реализация окна отображения вопроса и ввода ответа.
- Создание интерфейса выбора режима тренировки.
- Разработка экранов результатов, статистики и рекомендаций.
- Реализация визуального отображения прогресса пользователя.
- Интеграция интерфейса с остальными модулями приложения.

### Участник 3. Статистика игрока, тестирование и маркетинг
**Цель:** разработка системы анализа результатов пользователя и персонализированного подбора вопросов.

Задачи:
- Разработка классов User, Statistics, RecommendationSystem, TrainingSession.
- Реализация сохранения истории игр и ответов пользователя.
- Реализация алгоритма подсчёта статистики по тематическим категориям и уровням сложности.
- Реализация системы оценки прогресса пользователя.
- Тестирование алгоритмов на различных результатах тренировок.
- Презентация проекта.

## Общие задачи (выполняются совместно всеми участниками):
- Согласование архитектуры приложения и связей между классами.
- Определение единых интерфейсов взаимодействия между модулями.
- Настройка репозитория GitHub и структуры проекта.
- Интеграция разработанных модулей.
- Комплексное тестирование приложения.
- Демонстрация и защита готового проекта.
