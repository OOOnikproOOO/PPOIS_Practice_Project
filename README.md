# Интеллектуальный тренажёр «Своя игра»
Командный проект на C++ — интеллектуальный тренажёр для одного пользователя, основанный на механике телевизионной передачи «Своя игра».

Приложение позволяет проходить тематические вопросы, тренироваться по выбранным темам, просматривать свои результаты и повторять ошибки. Графический интерфейс выполнен в стиле телевизионного оформления 2000-х годов.

## Основные возможности
- Два режима: «Игра» и «Тренировка».
- Текстовые вопросы, вопросы с изображениями и аудиозаписями.
- Автоматическая проверка ответов с поддержкой альтернативных формулировок.
- Вопросы «Кот в мешке».
- Просмотр правильного ответа.
- Повторение ошибок после тренировки.
- Экран результатов и локальный архив сессий.
- Настройки музыки, звуков, экранных помех и выпуклости экрана.
- Полноэкранный режим и управление с клавиатуры.

## Режим «Игра»

Игровое поле состоит из шести тематических строк. В каждой теме доступны вопросы стоимостью 100, 200, 300, 400 и 500 баллов.

Пользователь выбирает тему и стоимость, вводит ответ и получает результат проверки:

- за правильный ответ начисляется стоимость вопроса;
- за неправильный ответ стоимость вычитается;
- кнопка «Показать ответ» открывает правильный ответ без изменения счёта.

В каждом раунде находятся три вопроса «Кот в мешке». При их открытии появляется случайная тема, после чего пользователь выбирает стоимость — 100 или 500 баллов.

Темы игрового поля и темы специальных вопросов не повторяются в пределах сессии. Для нового раунда необходимы шесть новых тем поля и три темы для вопросов «Кот в мешке». Если подходящих тем недостаточно, сессия завершается.

После прохождения поля следующий раунд начинается автоматически. Пользователь также может нажать «Завершить игру», чтобы сохранить результат и перейти к итогам.

## Режим «Тренировка»

Для запуска тренировки необходимо:

1. Выбрать темы из списка либо включить «Случайные темы».
2. Указать минимальную и максимальную стоимость вопросов.
3. Выбрать количество вопросов.
4. Нажать «Начать тренировку».

Приложение показывает доступное количество вопросов для выбранных параметров. Если запрошено больше, тренировка не запускается и выводится сообщение.

В тренировке правильные ответы приносят баллы, а ошибки не уменьшают счёт. Действие «Показать ответ» увеличивает счётчик ошибок и позволяет включить вопрос в последующее повторение.

После завершения доступны результаты и кнопка «Повторить ошибки». Она создаёт тренировку из вопросов, на которые пользователь ответил неверно или просмотрел ответ.

Кнопка «Завершить тренировку» позволяет закончить её досрочно. В результатах учитываются уже обработанные вопросы.

## Результаты и история

На экране результатов отображаются набранные баллы, количество правильных ответов и вопросы для повторения.

Графическое приложение сохраняет до 50 последних сессий в локальном архиве. Для каждой записи сохраняются имя пользователя, режим, дата, баллы и результаты ответов.

## Технологии и архитектура

- C++17 — игровое ядро и логика приложения.
- Qt 6, Qt Quick и QML — графический интерфейс.
- Qt Multimedia — воспроизведение аудио.
- SQLite — хранение и загрузка базы вопросов.
- GoogleTest и Qt Test — тестирование.
- CMake — сборка.
- GitHub и Pull Requests — совместная разработка.
- GitHub Actions — автоматические сборки, тестирование и проверка покрытия.

## Запуск готовой программы

Готовые сборки для Windows x64 доступны в разделе [Releases](https://github.com/OOOnikproOOO/PPOIS_Practice_Project/releases).

1. Скачайте архив графической версии из раздела Assets выбранного релиза.
2. Полностью распакуйте архив.
3. Запустите `OwnGameGui.exe`.

## Структура проекта

```text
include/             Заголовочные файлы игрового ядра
src/                 Реализация игрового ядра и SQLite
gui/                 Связующий слой, QML-интерфейс и ресурсы оформления
assets/              Изображения и аудиозаписи для вопросов
tests/               Модульные и интеграционные тесты
.github/workflows/   Автоматические проверки и сборки
CMakeLists.txt       Конфигурация сборки
main.cpp             Точка входа консольного приложения
```
